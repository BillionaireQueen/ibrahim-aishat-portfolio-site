# Ibrahim Aishat Omotolani — Portfolio Website

A modern, responsive portfolio website for **Ibrahim Aishat Omotolani** — AI Workflow Automation Developer, Resin Artist, Technical Author, Podcast Co-host, and Digital Entrepreneur.

## 🚀 How to Deploy to GitHub Pages (`.github.io`)

### Step 1: Create a GitHub Repository
1. Go to [GitHub.com/new](https://github.com/new).
2. Set the Repository name to: `ibrahim-aishat-portfolio-site` (or `billionairequeen.github.io`).
3. Set visibility to **Public** and click **Create repository**.

### Step 2: Push your local code
Open terminal in this directory and run:
```bash
git remote set-url origin https://github.com/billionairequeen/ibrahim-aishat-portfolio-site.git
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub: `https://github.com/billionairequeen/ibrahim-aishat-portfolio-site`
2. Click **Settings** ⚙️ at the top right.
3. Click **Pages** in the left sidebar menu.
4. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
5. Select Branch: **`main`**, Folder: **`/ (root)`**, and click **Save**.

Your portfolio website will be live at:
🌐 **`https://billionairequeen.github.io/ibrahim-aishat-portfolio-site/`**
